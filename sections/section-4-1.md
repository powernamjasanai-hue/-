## 4-1. 진짜 수익 계산하기

**승인 날짜:** 2025-11-02  
**상태:** 초안 작성 중

---

### 매출 100만원인데... 진짜 남는 게 얼마죠?

한 달 동안 광고를 돌렸습니다. 메타 광고 관리자를 보니 이렇습니다.

- 총 광고비: 300,000원
- 총 매출: 450,000원
- ROAS: 1.5

'오! 150,000원 벌었다!' 기뻐하려는 순간, 뭔가 이상합니다.

- 전자책 제작 비용 (디자이너 의뢰): 50,000원
- PG 수수료 (카드 결제 3.3%): 14,850원
- 랜딩 페이지 호스팅: 10,000원/월
- Canva 유료 플랜: 12,000원/월

이것들을 빼면... **실제 순이익은 63,150원**입니다. 생각보다 적습니다.

많은 초보자가 '매출 = 수익'으로 착각합니다. 하지만 비즈니스에서 중요한 건 **순이익**입니다. 이번 섹션에서는 진짜 돈이 얼마나 남는지 계산하는 법을 알려드립니다.

---

### 매출 vs 이익: 헷갈리는 개념 정리

디지털 제품 판매에는 네 가지 숫자가 있습니다. 이것들을 명확히 구분해야 합니다.

**① 매출 (Revenue)**
- 고객이 지불한 총 금액
- 예: 전자책 30,000원 × 15건 = 450,000원

**② 광고비 (Ad Spend)**
- 메타에 지불한 광고비
- 예: 300,000원

**③ 기타 비용 (Other Costs)**
- 제작비, 수수료, 구독료, 호스팅 등
- 예: 86,850원

**④ 순이익 (Net Profit)**
- 최종적으로 당신 손에 남는 돈
- 계산식: 매출 - 광고비 - 기타 비용
- 예: 450,000 - 300,000 - 86,850 = 63,150원

**왜 헷갈릴까?**  
메타 광고 관리자는 '매출'을 강조합니다. 'ROAS 1.5!'라고 보여주면서 성공한 것처럼 느껴지게 합니다. 하지만 실제로는 기타 비용을 빼야 진짜 순이익이 나옵니다. 특히 PG 수수료(3~4%)는 작아 보이지만 누적되면 큽니다. 매출 1,000만원이면 수수료만 30~40만원입니다.

---

### 진짜 수익 계산 공식 (5단계)

**Step 1: 매출 계산**
```
매출 = 제품 가격 × 판매 건수
```

예: 30,000원 × 15건 = 450,000원

---

**Step 2: 광고비 확인**
- 메타 광고 관리자 → '지출' 열 확인
- 예: 300,000원

---

**Step 3: 기타 비용 정리**

| 항목 | 금액 | 비고 |
|------|------|------|
| **제작비** | 50,000원 | 디자이너, 작가 등 (한 번만) |
| **PG 수수료** | 14,850원 | 매출 × 3.3% |
| **호스팅** | 10,000원 | 랜딩 페이지, 스토어 |
| **구독료** | 12,000원 | Canva, 이메일 서비스 등 |
| **총 기타 비용** | **86,850원** | |

**주의사항:**
- 제작비는 한 번만 들어가는 비용 (100개 팔아도 50,000원)
- PG 수수료는 매출에 비례 (매출이 늘면 수수료도 늘어남)
- 구독료는 고정 비용 (매출과 관계없이 매달 나감)

---

**Step 4: 순이익 계산**
```
순이익 = 매출 - 광고비 - 기타 비용
```

예: 450,000 - 300,000 - 86,850 = **63,150원**

---

**Step 5: 순이익률 계산 (중요!)**
```
순이익률 = (순이익 ÷ 매출) × 100
```

예: (63,150 ÷ 450,000) × 100 = **14.0%**

**순이익률 기준:**
- **20% 이상:** 매우 건강 (지속 가능)
- **10~20%:** 보통 (개선 여지 있음)
- **5~10%:** 위험 (비용 절감 필요)
- **5% 미만:** 적자 위험 (즉시 개선)

---

### 실전 계산 예시: 두 가지 시나리오

**시나리오 A: ROAS는 높은데 순이익은 낮음**

| 항목 | 금액 |
|------|------|
| 매출 | 500,000원 |
| 광고비 | 250,000원 (ROAS 2.0) |
| PG 수수료 | 16,500원 |
| 호스팅 | 10,000원 |
| 구독료 | 15,000원 |
| 제작비 | 100,000원 |
| **순이익** | **108,500원** |
| **순이익률** | **21.7%** |

**분석:** ROAS 2.0으로 좋아 보이지만, 제작비가 높아서 순이익률은 21.7%입니다. 제작비를 낮추거나 가격을 올리면 더 좋아집니다.

---

**시나리오 B: ROAS는 낮은데 순이익률은 높음**

| 항목 | 금액 |
|------|------|
| 매출 | 600,000원 |
| 광고비 | 400,000원 (ROAS 1.5) |
| PG 수수료 | 19,800원 |
| 호스팅 | 10,000원 |
| 구독료 | 12,000원 |
| 제작비 | 20,000원 (재사용) |
| **순이익** | **138,200원** |
| **순이익률** | **23.0%** |

**분석:** ROAS는 1.5로 낮지만, 제작비를 재사용해서 순이익률은 23.0%로 높습니다. 광고비를 줄여서 ROAS를 올리면 더 좋아집니다.

**교훈:** ROAS만 보지 말고 순이익률을 함께 봐야 합니다.

| 항목 | 현재 비용 | 절감 방법 | 절감액 |
|------|-----------|-----------|--------|
| **Canva** | 12,000원/월 | 무료 플랜으로 변경 (템플릿 충분) | 12,000원 |
| **호스팅** | 10,000원/월 | Notion, Carrd 등 무료 랜딩 페이지 | 10,000원 |

**주의:**
- 품질이 떨어지면 전환율 하락 → 오히려 손해
- 절감은 '불필요한 비용'만 (필수는 유지)
- 예: 디자인이 중요한 상품은 제작비 투자 권장

### 손익분기점 (BEP): 몇 개 팔아야 본전일까?

**손익분기점이란?**  
광고비와 기타 비용을 다 회수하려면 몇 개를 팔아야 하는가?

**계산식:**
```
손익분기점 = (광고비 + 기타 비용) ÷ (제품 가격 - PG 수수료)
```

**예시:**
- 광고비: 300,000원
- 기타 비용: 36,850원 (제작비 제외, 고정 비용만)
- 제품 가격: 30,000원
- PG 수수료: 30,000 × 3.3% = 990원
- 실제 단위당 수익: 30,000 - 990 = 29,010원

손익분기점 = (300,000 + 36,850) ÷ 29,010 = **11.6개**

**즉, 12개 팔면 본전, 13개부터 이익입니다.**

**활용법:**
- 광고 돌리기 전에 손익분기점 계산
- '하루 1개씩 팔면 30일이면 본전'처럼 현실성 판단
- 손익분기점이 너무 높으면 (30개 이상) 광고비 줄이기

### 표: 진짜 수익 계산 체크리스트

| 단계 | 항목 | 계산식 | 완료 |
|------|------|--------|------|
| **1** | 매출 | 가격 × 판매 건수 | ☐ |
| **2** | 광고비 | 메타 광고 관리자 '지출' 확인 | ☐ |
| **3** | 기타 비용 | 제작비 + PG + 호스팅 + 구독료 | ☐ |
| **4** | 순이익 | 매출 - 광고비 - 기타 비용 | ☐ |
| **5** | 순이익률 | (순이익 ÷ 매출) × 100 | ☐ |
| **6** | 손익분기점 | (광고비+기타비용) ÷ 단위수익 | ☐ |
| **7** | 비용 절감 | 불필요한 구독 취소 | ☐ |

### 핵심 요약: 다음 단계로 가기 전에

**이번 섹션에서 배운 개념:**
- 매출 ≠ 순이익 (기타 비용을 빼야 진짜 남는 돈)
- 순이익률이 20% 이상이어야 건강
- 손익분기점을 미리 계산해야 현실성 판단 가능

**실용 지식:**
- 순이익 = 매출 - 광고비 - 기타 비용
- PG 수수료는 작아 보여도 누적되면 큼 (3.3%)
- 불필요한 구독료 취소만 해도 월 10만원 절감 가능

**지금 바로 해야 할 것:**
1. [ ] 지난 한 달 매출, 광고비, 기타 비용 정리
2. [ ] 순이익과 순이익률 계산
3. [ ] 손익분기점 계산해서 현실성 확인
4. [ ] 불필요한 구독료 찾아서 취소

**다음 섹션 예고:**  
순이익을 계산했습니다. 이제 '어떻게 지속적으로 개선할까?'가 중요합니다. 다음 섹션에서는 매달 광고 성과를 리뷰하고 개선하는 루틴을 알려드립니다.
