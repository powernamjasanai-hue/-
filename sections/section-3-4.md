## 3-4. 문제 해결 가이드 (광고 승인 거부, 계정 문제)

**승인 날짜:** 2025-11-02  
**상태:** 초안 작성 중

---

### '광고가 거부되었습니다' 이메일을 받았어요

광고를 처음 세팅하고 '게시' 버튼을 눌렀습니다. 10분 후, 메타에서 이메일이 왔습니다.

**제목: "광고가 거부되었습니다"**

당황스럽습니다. 뭐가 문제일까요?

- '저희 전자책은 메타 광고 초보자를 위한...' → 거부
- '7일 만에 광고 마스터!' → 거부  
- 랜딩 페이지에 이메일 수집 폼 → 거부

메타는 왜 이렇게 까다로울까요? 이번 섹션에서는 광고 승인 거부와 계정 문제를 해결하는 법을 알려드립니다.

---

### 메타가 광고를 거부하는 진짜 이유

메타는 매일 수백만 개의 광고를 검토합니다. 사람이 직접 보는 것도 있지만, 대부분은 **AI 자동 검토 시스템**이 판단합니다. 이 AI는 과거 수십억 개의 광고 데이터를 학습했습니다. 그래서 때로는 멀쩡한 광고도 '의심스럽다'고 판단해서 거부합니다. 메타가 광고를 거부하는 핵심 이유는 세 가지입니다. **첫째, 사용자 경험 보호입니다.** 메타의 수익은 광고에서 나오지만, 사용자들이 페이스북과 인스타그램을 떠나면 수익도 사라집니다. 그래서 '사기성 광고', '과장 광고', '불쾌한 광고'를 엄격하게 차단합니다. 예를 들어 '클릭 한 번에 100만원 벌기!'같은 광고는 즉시 거부됩니다. 사용자들이 이런 광고에 속아서 메타를 불신하게 되는 걸 막기 위해서입니다. **둘째, 법적 규제 준수입니다.** 메타는 전 세계 200개국에서 사업합니다. 각 나라마다 광고 규제가 다릅니다. 한국에서는 '의료 효능'을 주장하는 광고가 불법이고, 유럽에서는 '개인정보 수집'에 엄격합니다. 메타는 각국 법을 어기면 수조 원의 벌금을 내야 하므로, 의심스러운 광고는 먼저 차단합니다. **셋째, 브랜드 이미지 보호입니다.** 메타는 '신뢰할 수 있는 플랫폼'이라는 이미지를 지키려고 합니다. 그래서 '선정적', '폭력적', '정치적으로 논란 많은' 광고는 거부합니다. 이 세 가지 기준을 이해하면, 왜 당신의 광고가 거부되었는지 짐작할 수 있습니다.

---

### 광고 승인 거부 5대 원인과 해결책

#### **원인 1: 과장되거나 비현실적인 주장**

**거부된 예시:**
- '하루 만에 100만원 벌기'
- '7일 만에 광고 전문가 되기'
- '클릭 한 번에 자동 수익'

**왜 거부되나?**  
메타는 '비현실적인 수익 주장'을 금지합니다. 사용자를 속이는 광고로 간주합니다.

**해결책:**
- 과장 표현 제거
- 구체적인 조건 명시
- 수정 예: '초보자를 위한 메타 광고 기초 가이드' (결과 약속 안 함)

---

#### **원인 2: 금지된 콘텐츠**

**금지 카테고리:**
- 성인 콘텐츠 (노출, 선정성)
- 담배, 마약, 무기
- 도박, 불법 서비스
- 가짜 뉴스, 정치 광고 (특별 승인 필요)

**의외로 걸리는 것들:**
- '다이어트 알약' → 건강 효능 주장으로 거부
- '빠른 대출' → 금융 규제 위반으로 거부
- '정부 지원금' → 정치 광고로 오인되어 거부

**해결책:**
- 메타 광고 정책 페이지 확인 (business.facebook.com/policies/ads)
- 금지 단어 피하기 ('보증', '치료', '승인 보장' 등)

---

#### **원인 3: 개인정보 타겟팅 언급**

**거부된 예시:**
- '30대 직장인이세요? 이 제품이 필요합니다'
- '서울에 사시는 분들을 위한 특별 할인'
- '최근에 광고 클릭하셨죠?'

**왜 거부되나?**  
메타는 '개인 속성을 직접 언급'하는 것을 금지합니다. 사용자가 '내 정보가 노출되었나?'라고 불안해하기 때문입니다.

**해결책:**
- 나이, 지역, 행동 직접 언급 금지
- 수정 예: '직장인을 위한' → 'OK', '30대 직장인을 위한' → 'X'

---

#### **원인 4: 랜딩 페이지 품질 문제**

**거부 사유:**
- 광고와 랜딩 페이지 내용 불일치
- 랜딩 페이지 로딩 안 됨 (404 에러)
- 팝업 과다
- 자동 다운로드

**예시:**
- 광고: '무료 전자책' → 랜딩: 유료 판매 페이지 (불일치로 거부)
- 랜딩 페이지가 모바일에서 깨짐 (품질 낮음으로 거부)

**해결책:**
- 광고와 랜딩 페이지 메시지 일치
- 모바일 최적화 확인
- 팝업 제거 또는 최소화
- 로딩 속도 체크 (3초 이내)

---

#### **원인 5: 텍스트 과다 이미지**

**2020년 이전 규칙:**
- 이미지의 20% 이상이 텍스트면 거부

**2025년 현재:**
- 규칙 완화되었지만, 여전히 '텍스트 과다'는 성과 저하 경고

**권장:**
- 이미지의 30% 미만만 텍스트
- 핵심 메시지만 간결하게

---

### 표: 광고 거부 자가 진단 체크리스트

| 항목 | 체크 | 위험도 |
|------|------|--------|
| '100만원', '보장', '치료' 같은 과장 단어 사용? | ☐ | 높음 |
| 나이/지역/직업 직접 언급? (예: '30대 서울 직장인') | ☐ | 높음 |
| 광고와 랜딩 페이지 메시지가 다름? | ☐ | 중간 |
| 랜딩 페이지 모바일에서 깨짐? | ☐ | 중간 |
| 이미지의 50% 이상이 텍스트? | ☐ | 낮음 |
| 선정적/폭력적 이미지? | ☐ | 높음 |

**하나라도 체크되면 수정 권장**

---

### 광고 거부되었을 때 대응법 (3단계)

#### **Step 1: 거부 사유 확인 (1분)**

**메타 광고 관리자:**
- 거부된 광고 클릭
- '거부 사유 보기' 클릭
- 메타가 제시한 정확한 이유 확인

**흔한 거부 사유:**
- '금지된 콘텐츠'
- '개인 속성 언급'
- '오해의 소지가 있는 주장'
- '랜딩 페이지 품질'

---

#### **Step 2: 광고 수정 (10분)**

**거부 사유별 수정:**

| 거부 사유 | 수정 방법 |
|-----------|-----------|
| **과장 주장** | 숫자 제거 또는 조건 명시 ('7일 완성' → '초보자 가이드') |
| **개인 속성** | 나이/지역 삭제 ('30대 직장인' → '직장인') |
| **랜딩 페이지** | URL 확인, 모바일 테스트, 메시지 일치 |
| **금지 콘텐츠** | 금지 단어 제거, 카테고리 변경 |

---

#### **Step 3: 재심사 요청 또는 새 광고 만들기**

**옵션 A: 재심사 요청**
- 거부된 광고 → '재심사 요청' 버튼
- 간단한 설명 작성 (100자 이내)
- 예: '과장 표현을 제거했습니다. 재검토 부탁드립니다.'
- 보통 24시간 이내 결과

**옵션 B: 새 광고 만들기 (권장)**
- 거부된 광고 복사
- 문제 부분 수정
- 새로 게시
- 더 빠름 (10분~1시간 승인)

**주의:** 같은 내용으로 계속 재신청하면 계정 제한 위험

---

### 계정 정지/제한 문제

#### **증상:**
- '광고 계정이 정지되었습니다' 메시지
- 새 광고 만들기 버튼 비활성화
- 결제 수단 추가 불가

#### **원인:**

| 원인 | 설명 |
|------|------|
| **반복된 정책 위반** | 광고 거부 5회 이상 → 계정 정지 |
| **결제 문제** | 카드 결제 실패, 미납금 |
| **의심스러운 활동** | 짧은 시간에 광고 대량 생성 |
| **신규 계정** | 계정 만든 지 1주일 미만 (학습 단계) |

#### **복구 방법:**

**Step 1: 계정 상태 확인**
- Meta Business Suite → 설정 → 계정 품질
- 정지 사유 확인

**Step 2: 이의 제기**
- '이의 제기' 버튼 클릭
- 간단한 설명 작성 (왜 정지되었고, 어떻게 개선했는지)
- 예: '광고 정책을 충분히 숙지하지 못했습니다. 모든 과장 표현을 제거했으며, 앞으로 정책을 준수하겠습니다.'

**Step 3: 메타 지원팀 연락**
- 이의 제기 후 3-5일 대기
- 응답 없으면 Meta Business 지원 채팅
- business.facebook.com/business/help → 채팅 시작

**Step 4: 안 되면 새 계정? (최후 수단)**
- 기존 계정이 영구 정지되면 새 계정 고려
- 주의: 같은 결제 수단 사용 금지 (연결되어 또 정지됨)
- 새 비즈니스 관리자 + 새 카드 필요

---

### 예방이 최선: 계정 건강 유지 루틴

**매주 체크:**
- 계정 품질 점수 확인 (Meta Business Suite → 계정 품질)
- 점수 낮으면 경고 광고 수정

**광고 만들 때:**
- 금지 단어 체크리스트 사용
- 랜딩 페이지 모바일 테스트
- 과장 표현 자제

**계정 신뢰도 쌓기:**
- 처음 1개월은 하루 1만원 이하로 조심스럽게
- 정책 위반 없이 광고 10개 이상 승인받기
- 결제 정보 정확하게 입력, 정시 결제

### 핵심 요약: 다음 단계로 가기 전에

**이번 섹션에서 배운 개념:**
- 메타가 광고를 거부하는 3가지 이유 (사용자 보호, 법 준수, 브랜드 이미지)
- 5대 거부 원인 (과장, 금지 콘텐츠, 개인정보, 랜딩 페이지, 텍스트 과다)
- 계정 정지는 반복 위반 시 발생

**실용 지식:**
- 광고 거부 시 3단계 대응 (사유 확인 → 수정 → 재신청)
- 계정 정지 시 이의 제기 방법
- 예방 루틴 (계정 품질 점수 주간 체크)

**지금 바로 해야 할 것:**
1. [ ] 현재 광고에 금지 단어 있는지 체크
2. [ ] 랜딩 페이지 모바일에서 확인
3. [ ] 계정 품질 점수 확인 (Meta Business Suite)
4. [ ] 금지 단어 체크리스트 북마크

**다음 섹션 예고:**  
문제는 해결했습니다. 이제 Part 4 마지막 섹션입니다. '메타 픽셀 기초'에서 전환 추적을 더 정확하게 하는 법을 알려드립니다 (선택사항).
