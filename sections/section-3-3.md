## 3-3. 언제 끄고, 언제 키울까?

**승인 날짜:** 2025-11-02  
**상태:** 초안 작성 중

---

### 7일째인데... 계속 돌려야 할까요?

광고를 돌린 지 7일이 지났습니다. 숫자는 이렇습니다.

- CTR: 1.1%
- CPC: 950원
- 클릭: 73명
- 구매: 2명 (전환율 2.7%)
- 총 지출: 69,350원
- 총 매출: 60,000원 (전자책 30,000원 × 2)
- **손실: -9,350원**

돈을 잃고 있습니다. 이제 어떻게 해야 할까요?

- A안: 광고를 끄고 포기한다
- B안: 조금 더 기다린다
- C안: 소재를 바꾸고 다시 시작한다

많은 초보자가 이 시점에서 'A안'을 선택합니다. '역시 나는 안 되나 봐...' 하면서 광고를 끕니다. 하지만 **7일 만에 포기하는 것은 너무 이릅니다.** 이번 섹션에서는 과학적인 판단 기준을 알려드립니다.

---

### 광고 판단의 3가지 타이밍: 왜 7일, 14일, 30일인가?

메타 광고는 '학습 단계'를 거칩니다. AI가 '어떤 사람에게 이 광고를 보여주면 클릭/구매할까?'를 배우는 과정입니다. 이 학습에는 시간이 필요합니다. 메타 공식 문서에 따르면 광고 세트가 '학습 완료' 상태가 되려면 **7일 동안 50회 이상의 전환(클릭 또는 구매)이 필요합니다.** 7일이 안 됐다면 AI는 아직 제대로 학습하지 못한 것입니다. 그래서 광고 판단에는 세 가지 타이밍이 있습니다. **① 7일차: 첫 번째 점검.** AI 학습이 어느 정도 완료되었습니다. CTR과 CPC를 보고 '소재의 기본 매력'을 판단합니다. CTR이 0.5% 이하라면 소재가 약한 것이므로 즉시 교체합니다. **② 14일차: 두 번째 점검.** 충분한 데이터가 쌓였습니다. 전환율을 보고 '랜딩 페이지의 설득력'을 판단합니다. 전환율이 2% 이하라면 랜딩 페이지를 개선하거나 가격을 재검토합니다. **③ 30일차: 최종 판단.** ROAS(광고 투자 대비 수익)를 계산합니다. ROAS 1.0 이상이면 계속 진행, 0.7 이하면 중단, 0.7~1.0이면 개선 후 재시도입니다. 이 타이밍을 지키지 않고 3일 만에 포기하면 AI가 학습할 기회조차 주지 않는 것입니다. 반대로 60일 동안 손실을 보면서 계속 돌리는 것도 위험합니다. 타이밍이 중요합니다.

---

### 판단 기준표: 7일, 14일, 30일에 뭘 봐야 하나?

| 타이밍 | 체크 지표 | 판단 기준 | 조치 |
|--------|-----------|-----------|------|
| **7일차** | CTR | 1.0% 이상 | 계속 진행 |
| | | 0.5~1.0% | 소재 A/B 테스트 병행 |
| | | 0.5% 미만 | 소재 즉시 교체 |
| **14일차** | CTR + 전환율 | CTR 1.0% + 전환율 3% 이상 | 계속 진행 |
| | | CTR 괜찮은데 전환율 2% 이하 | 랜딩 페이지 개선 |
| | | 둘 다 낮음 | 전면 재검토 |
| **30일차** | ROAS | 1.5 이상 | 예산 증액 (스케일링) |
| | | 1.0~1.5 | 유지, 소재 개선 지속 |
| | | 0.7~1.0 | 개선 후 재시도 |
| | | 0.7 미만 | 중단 고려 |

**ROAS 계산법:**
```
ROAS = 총 매출 ÷ 총 광고비
```

예:
- 광고비 100만원, 매출 150만원 → ROAS 1.5
- 광고비 100만원, 매출 80만원 → ROAS 0.8

### 실전 시나리오: 이럴 때 어떻게 할까?

**시나리오 1: 7일차, CTR 0.4%, 손실 중**
- **문제:** 소재가 너무 약함
- **판단:** 즉시 중단
- **조치:** 이미지와 카피 전면 교체 후 새 광고 시작
- **이유:** AI가 학습할 데이터가 너무 적음 (클릭이 안 되므로)

**시나리오 2: 14일차, CTR 1.5%, 전환율 1.2%, 손실 중**
- **문제:** 광고는 매력적인데 랜딩 페이지가 약함
- **판단:** 광고는 유지, 랜딩 페이지 개선
- **조치:** 
  - 고객 후기 추가
  - 환불 보장 문구 추가
  - 가격 재검토 (할인 테스트)
  - 모바일 화면 최적화
- **이유:** CTR이 좋다는 건 제품에 관심은 있다는 뜻. 설득만 잘하면 전환 가능

**시나리오 3: 30일차, CTR 1.8%, 전환율 5.5%, ROAS 1.4**
- **문제:** 없음! 수익 중
- **판단:** 성공
- **조치:** 예산 점진적 증액 (하루 1만원 → 1.5만원 → 2만원)
- **이유:** 검증된 광고는 예산을 늘려도 효율 유지 가능

**시나리오 4: 30일차, CTR 1.2%, 전환율 3.8%, ROAS 0.9**
- **문제:** 손익분기점 근처
- **판단:** 보류
- **조치:** 
  - 한 달 더 테스트 (계절성 또는 학습 완료 확인)
  - 동시에 소재 개선 버전 A/B 테스트
- **이유:** 조금만 개선하면 흑자 가능. 포기하기엔 아까움

**시나리오 5: 30일차, CTR 0.7%, 전환율 2.1%, ROAS 0.5**
- **문제:** 전면 실패
- **판단:** 중단
- **조치:** 
  - 제품 자체 재검토 (시장 수요가 있는가?)
  - 타겟 고객 재정의
  - 가격 대비 가치 재검토
- **이유:** 30일 동안 개선 없이 계속 손실이면 근본 문제가 있음

### 예산 증액 (스케일링): 언제, 얼마나 올릴까?

광고가 성공하면 '스케일링'을 고려해야 합니다. 하루 1만원으로 ROAS 1.5가 나온다면, 하루 10만원으로 늘리면 수익이 10배가 될까요?

**아닙니다.** 예산을 급격히 늘리면 AI가 다시 '학습 단계'에 들어가고, 효율이 떨어집니다.

**안전한 스케일링 원칙:**

| 원칙 | 설명 | 예시 |
|------|------|------|
| **점진적 증액** | 한 번에 20~30% 이내 | 1만원 → 1.2만원 → 1.5만원 |
| **3~4일 간격** | 증액 후 최소 3일 관찰 | 월요일 증액 → 목요일 다시 증액 |
| **ROAS 모니터링** | 증액 후 ROAS 10% 이하 하락은 정상 | ROAS 1.5 → 1.35는 OK |
| **20% 이상 하락 시 중단** | ROAS 1.5 → 1.2 이하면 위험 | 예산 원래대로 복구 |

**스케일링 타임라인 예시:**

| 날짜 | 일일 예산 | ROAS | 조치 |
|------|-----------|------|------|
| 1-30일 | 10,000원 | 1.5 | 검증 완료 |
| 31-33일 | 12,000원 | 1.45 | 정상, 계속 |
| 34-36일 | 15,000원 | 1.42 | 정상, 계속 |
| 37-39일 | 18,000원 | 1.3 | 조금 하락, 관찰 |
| 40-42일 | 18,000원 유지 | 1.35 | 회복, 유지 |
| 43일- | 20,000원 | 1.32 | 안정화, 최종 예산 확정 |

### 중단 vs 일시정지: 차이가 뭔가요?

메타 광고 관리자에는 '일시정지'와 '삭제(중단)' 두 가지 옵션이 있습니다.

**일시정지 (Pause):**
- AI 학습 데이터 유지됨
- 재개 시 학습 단계 짧음
- 일시적 예산 부족, 재고 소진 등에 사용

**삭제 (Delete):**
- AI 학습 데이터 사라짐
- 다시 시작하면 처음부터 학습
- 완전히 실패한 광고에만 사용

**권장:**
- 7일 미만 광고: 일시정지 (다시 개선해서 재개 가능)
- 30일 이상 실패 광고: 삭제 (데이터가 오히려 방해)
- 계절 상품 (수능 전자책 등): 시즌 끝나면 일시정지, 내년에 재개

### 핵심 요약: 다음 단계로 가기 전에

**이번 섹션에서 배운 개념:**
- 광고는 7일, 14일, 30일 타이밍에 판단
- 7일차는 CTR, 14일차는 전환율, 30일차는 ROAS 중심
- 예산 증액은 점진적으로 (20~30% 이내)

**실용 지식:**
- ROAS 1.5 이상이면 스케일링, 0.7 미만이면 중단
- 일시정지와 삭제의 차이 (학습 데이터 보존 여부)
- 급격한 예산 증액은 AI 학습을 망가뜨림

**지금 바로 해야 할 것:**
1. [ ] 현재 광고가 며칠째인지 확인
2. [ ] 타이밍에 맞는 지표 확인 (7일차→CTR, 14일차→전환율, 30일차→ROAS)
3. [ ] 판단 기준표와 비교해서 조치 결정
4. [ ] 성공 시 스케일링 계획 세우기 (20% 증액, 3일 간격)

**다음 섹션 예고:**  
광고를 성공적으로 돌렸습니다! 이제 Part 4로 넘어갑니다. '성과 측정과 개선'입니다. 광고비 대비 얼마나 벌었는지 정확히 계산하고, 지속적으로 개선하는 방법을 알려드립니다.
