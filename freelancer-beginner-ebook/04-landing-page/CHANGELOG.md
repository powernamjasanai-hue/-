# 랜딩페이지 카피 변경 이력

## 2025-11-02 - 개선본 (final-landing-page-copy-revised.md)

### 주요 개선사항

#### 1. 섹션 1: 3개 고객 그룹 공감 추가
**변경 전:**
- 단일 헤드카피 (성장 정체 프리랜서만)

**변경 후:**
- 3개 그룹 모두 포괄하는 헤드카피
- 각 그룹별 공감 문장:
  - 초보 (0-1년): "이 가격 받아도 되는 걸까?"
  - 성장 정체 (1-3년): "포트폴리오 20개인데 왜 단가는 그대로?"
  - 번아웃 위험 (3-5년): "일은 많은데 번아웃이 올 것 같아요"

#### 2. 섹션 4: 거짓 내용 제거
**변경 전:**
```
결과는? 첫 달 매출 3,500만원.
클라이언트는 너무 만족해서 다음 제품도 500만원에 의뢰했습니다.
```

**변경 후:**
```
대표님은 만족하셨고,
그 후 다음 제품도 500만원에 의뢰하셨습니다.
```

**전자책도 동시 수정**: chapter-01-value-design.md에서 동일하게 수정

#### 3. 확언/과장 표현 제거
**변경 전 → 변경 후:**
- "단가를 3배 올릴 수 있습니다" → "저는 10만원에서 평균 300만원까지 받게 됐습니다"
- "이 책이 여러분의 5년을 바꿀 수 있습니다" → "이 책은 여러분의 5년을 압축할 수 있습니다"
- "단가가 3배 올라갑니다" → "재계약률이 올라갑니다"
- "더 당당해집니다" → 유지 (상대적 표현이므로 OK)

#### 4. 섹션 11 제거
**제거된 섹션:**
- 1.4억 웨비나 퍼널 상세 사례
- 3가지 대표 사례 (화장품 브랜드, 건강기능식품 등)

**이유:** 중복 + 과장처럼 보일 수 있음

**유지된 부분:**
- 섹션 10에 "클라이언트 성과: 웨비나 퍼널 하나로 1.4억 매출"은 숫자로만 간략히 유지

#### 5. 전체 톤 조정
**핵심 원칙:**
- ❌ "~할 수 있습니다" (확언, 약속)
- ✅ "저는 ~했습니다" (실제 경험)
- ❌ "여러분도 ~하게 됩니다" (보장)
- ✅ "여러분도 시행착오를 줄일 수 있습니다" (가능성)

**구체적 변경:**
```
변경 전: "이 6가지만 알면, 지금 실력 그대로도 단가를 3배 올릴 수 있습니다."
변경 후: "이 6가지를 배우고 나서, 저는 10만원에서 평균 300만원까지 받게 됐습니다."

변경 전: "여러분은 당당해집니다"
변경 후: "더 당당해집니다" (정도의 차이 표현)

변경 전: "단가가 3배 올라갑니다"
변경 후: "재계약률이 올라갑니다" (측정 가능한 것으로)
```

- **순서**: 동일 유지

## 개선 원칙 정리

### ✅ 유지할 것
- 실제 경험 기반 스토리텔링
- 구체적 숫자 (10만원 → 300만원 → 1000만원)
- 실패 사례 공유 (30만원 영혼 팔았던 날)
- 6가지 원칙 구조

### ❌ 제거한 것
- 확언/보장 ("~할 수 있습니다")
- 거짓 성과 (3,500만원)
- 과도한 사례 나열 (섹션 11)
- 사기처럼 보이는 멘트

### 🔄 변경한 것
- "여러분은 ~됩니다" → "저는 ~했습니다"
- "~할 수 있습니다" → "저는 ~하게 됐습니다"
- 3개 그룹 모두 포괄하도록 섹션 1 확장
