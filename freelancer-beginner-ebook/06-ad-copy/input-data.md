# 📋 인풋 데이터

## 1. 제품/서비스 기본 정보

```
제품/서비스명: 프리랜서 초보자를 위한 입문 가이드

제품/서비스 카테고리: 전자책 (프리랜서 교육/자기계발)

핵심 기능/특징 (3가지):
1) 5년간 10만원→300만원→1000만원 성장한 실제 경험 기반 6가지 원칙
2) 성공만이 아닌 실패 경험 포함, 정직한 타임라인 (3개월 아닌 5년)
3) 즉시 적용 가능한 구체적 체크리스트와 협상 스크립트 제공

가격대:
- 최저가: 미정 (런칭 특가 예정)
- 최고가: 미정
- 권장가: 29,000원 수준 예상
```

## 2. 타겟 고객 정보

```
주요 타겟 고객 (3개 세그먼트):

세그먼트 1: 이제 막 시작한 초보 프리랜서
- 직업/역할: 신규 프리랜서 (경력 0-1년)
- 연령대: 25-35세
- 현재 겪는 주요 문제:
  - 가격 책정 기준이 없어서 10만원, 20만원 받아도 되는지 불안
  - 클라이언트가 "얼마면 돼요?"라고 물으면 당황
  - 지인 외주는 받았지만 '진짜 클라이언트'와 일하는 게 두려움
- 원하는 이상적 결과:
  - 자신감 있게 가격 제시하기
  - 첫 프로젝트 성공적으로 완수하기
  - 재계약 받기
- 과거 유사 제품 사용 경험:
  - 유튜브 단편 영상, 블로그 글 참고 정도
  - 체계적인 프리랜서 교육 받은 적 없음

세그먼트 2: 성장 정체 프리랜서 (1-3년차)
- 직업/역할: 중급 프리랜서 (경력 1-3년)
- 연령대: 27-40세
- 현재 겪는 주요 문제:
  - 포트폴리오 20개 넘게 쌓였는데 단가는 그대로
  - 바쁘게 일하는데 통장은 여전히 비어있음
  - 협상할 때마다 밀리고, 클라이언트 요구에 끌려다님
  - 일당 10만원에서 벗어나지 못함
- 원하는 이상적 결과:
  - 단가 2-3배 올리기
  - 협상 주도권 가져오기
  - 프로젝트 선택권 갖기
- 과거 유사 제품 사용 경험:
  - 프리랜서 커뮤니티 활동
  - 온라인 강의 1-2개 구매했지만 막연한 조언만 들음
  - "실력을 키워라", "포트폴리오를 쌓아라" 같은 뜬구름 잡는 이야기에 지침

세그먼트 3: 번아웃 위기 프리랜서 (3년+)
- 직업/역할: 고급 프리랜서 (경력 3년 이상)
- 연령대: 30-45세
- 현재 겪는 주요 문제:
  - 일은 많은데 번아웃이 올 것 같음
  - 고단가는 받지만 시간 관리 안 되고 삶의 질 하락
  - 재계약은 받지만 클레임과 수정 요청에 지침
  - 10년 후에도 이렇게 일할 수 있을지 불안
- 원하는 이상적 결과:
  - 지속 가능한 시스템 구축
  - 일과 삶의 균형
  - 번아웃 없이 10년 후에도 행복하게 일하기
- 과거 유사 제품 사용 경험:
  - 여러 교육 콘텐츠 소비했지만 단기 성과에만 집중
  - 장기적 지속가능성 다룬 콘텐츠는 못 봄
```

## 3. 경쟁 상황

```
주요 경쟁사/대체재:
- 프리랜서 온라인 강의 (클래스101, 패스트캠퍼스 등)
- 프리랜서 커뮤니티 (크몽, 프리모아 등)
- 유튜브 무료 콘텐츠
- 비즈니스 자기계발서

우리 제품의 차별점:
- "3개월에 월 1000만원" 같은 과장 없음 → "5년 걸렸습니다" 정직함
- 성공 사례만이 아닌 실패 경험 포함 (30만원 소고기집 프로젝트 등)
- 막연한 조언이 아닌 즉시 쓸 수 있는 체크리스트/스크립트
- 단기 성과가 아닌 10년 후까지 쓸 수 있는 원칙
- 실력 키우기가 아닌 '원칙'으로 단가 올리기

경쟁사 대비 가격:
- 온라인 강의: 10-30만원 (우리는 전자책으로 더 저렴)
- 코칭/컨설팅: 50-200만원 (우리는 자가학습형)
- 무료 콘텐츠: 0원 (우리는 체계적 정리 + 실전 자료)

경쟁사를 써본 고객들의 불만사항:
- "성공 사례만 보여주고 어떻게 했는지는 안 알려줌"
- "실력을 키워라, 포트폴리오를 쌓아라 같은 뜬구름 잡는 이야기"
- "3개월에 월 1000만원 같은 거짓말"
- "당장 써먹을 수 있는 스크립트나 템플릿이 없음"
- "장기적으로 지속 가능한 방법은 안 나옴"
```

## 4. 일상의 변화 (Before → After)

```
고객이 제품 사용 전 겪던 구체적 상황:
- 클라이언트: "얼마면 돼요?" → 나: "음... 50만원이요?" (떨리는 목소리)
- 포트폴리오 20개 쌓였는데 단가는 여전히 10-20만원
- 협상 때마다 밀리고 클라이언트 요구에 끌려다님
- 프로젝트 끝나고 재계약 못 받고 새 클라이언트 찾기 반복
- "실력 키우면 단가 오르겠지" 믿으며 무작정 일함

제품 사용 후 달라진 구체적 상황:
- 클라이언트: "얼마면 돼요?" → 나: "프로젝트 범위부터 정리해볼까요?" (협상 주도)
- 같은 실력인데 가격 설계 원칙 적용해서 100만원 → 300만원 제시
- 협상 체크리스트 보며 클라이언트 니즈 파악, 주도권 가져옴
- 시스템 관리로 재계약률 올라가서 새 클라이언트 찾는 시간 줄어듦
- 단기 성과가 아닌 10년 쓸 원칙으로 지속가능하게 일함

구체적 수치로 표현된 변화:
- 단가: 10만원 → 300만원 (5년간)
- 협상 성공률: 떨리며 제시 → 체크리스트로 주도권
- 재계약률: 프로젝트마다 새 클라이언트 찾기 → 기존 클라이언트 재계약
- 시간: 막연히 "실력 키우기" → 6가지 원칙 적용
- 타임라인: "3개월에 성공" 거짓말 → "5년 걸렸습니다" 정직
```
