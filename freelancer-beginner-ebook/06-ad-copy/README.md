# 📢 메타 광고 카피 디렉토리

전자책 '프리랜서 초보자를 위한 입문 가이드'의 메타(페이스북/인스타그램) 광고 카피라이팅 자료입니다.

## 📁 파일 구조

### 1. `input-data.md` / `input-data.txt`
광고 카피 작성을 위한 기초 데이터
- 제품/서비스 기본 정보
- 타겟 고객 3개 세그먼트 분석
- 경쟁 상황 및 차별점
- Before → After 변화
- 프로모션 정보

### 2. `meta-ad-copies.md` / `meta-ad-copies.txt`
전체 15개 광고 카피 (세그먼트별 5개씩)
- 세그먼트 1: 초보 프리랜서 (0-1년) - 5개
- 세그먼트 2: 성장 정체 프리랜서 (1-3년) - 5개
- 세그먼트 3: 번아웃 위기 프리랜서 (3년+) - 5개
- A/B 테스트 추천 조합
- 크리에이티브 제안

### 3. `top-recommended-copies.md`
최종 추천 TOP 3 카피 + 실행 가이드
- 🥇 1순위: 성장 정체 타겟 (ROAS 최고)
- 🥈 2순위: 초보 타겟 (전환율 높음)
- 🥉 3순위: 번아웃 타겟 (차별화)
- A/B 테스트 3단계 전략
- 예상 성과 지표
- 실행 체크리스트

## 🎯 카피 작성 방법론

### 4가지 핵심 카피 공식
1. **공식 1**: 고객이 원하는 순간 + 솔루션 제시
2. **공식 2**: 구체적인 문제상황 + 솔루션 제시
3. **공식 3**: 무료 베네핏 제시
4. **공식 4**: 고객이 원치 않는 순간 + 솔루션 제시

### 7가지 전환 촉진 개념
- **A**: 구체적 숫자/시간 제시
- **B**: 사회적 증거 (간접 제시)
- **C**: 긴급성 (시간 제한)
- **D**: 리스크 제거 (안심 장치)
- **E**: 손실 회피 프레이밍
- **F**: 간편성 극대화
- **G**: 대조 효과 (Before → After)

## 🏆 최종 추천 카피 (1순위)

### 메인 카피
```
포트폴리오 20개 쌓았는데 여전히 10만원?
5,200명이 바꾼 방법
```

### 서브 카피
```
실력 키우기 말고 원칙 바꾸기, 지금 바로 적용
```

**타겟**: 성장 정체 프리랜서 (1-3년차)
**예상 ROAS**: 400-600%
**이유**: 가장 절실한 페인포인트 + 손실회피 프레이밍 + 사회적 증거
